# World Horizon art references

Both images are original ImageGen concepts created for World Horizon.

- [Lobby](coastal-lobby.png) guides the live limestone terrace, circular stone stage, warm hero lighting, and dark teal settings panel.
- [Gameplay](coastal-gameplay.png) guides the timber and stone build finishes, water and atmosphere palette, tire smoke, and paired skid marks.

The game renders both scenes live in Three.js.
